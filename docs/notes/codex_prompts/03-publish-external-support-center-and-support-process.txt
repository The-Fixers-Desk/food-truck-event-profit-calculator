PRIMARY OBJECTIVE

IMPORTANT BOUNDARY

Implement only what the current repository can legitimately publish or prepare. If the public website is maintained in a separate repository or external platform, create the complete support-page content, structure, assets, and deployment handoff rather than pretending deployment occurred.

REQUIRED SCOPE

1. Product-specific support page

Create a support page for the Food Truck Event Profit Calculator with a stable product-specific URL.

The page should include:

Installation:
- Windows installation steps;
- macOS installation steps;
- where to find the downloaded file;
- installer or disk-image steps;
- first launch.

Launch and security warnings:
- Windows security warning guidance;
- macOS Gatekeeper or unidentified-developer guidance, if relevant;
- app will not open;
- app opens and immediately closes;
- missing shortcut or application location.

Reinstall and data:
- safe reinstall instructions;
- whether reinstall affects local data;
- where application data is stored;
- backup before reinstall;
- uninstall guidance.

Backup and recovery:
- exporting a backup;
- importing a backup;
- invalid or incompatible backup file;
- recovery safeguards;
- what to include when requesting help.

Known issues:
- a clearly marked section;
- do not invent issues;
- support an empty “No known issues” state if appropriate;
- include app-version context.

Contact:
- email contact@fixersdesk.com;
- request operating system, app version, exact error text, steps already tried, and screenshots;
- state that support begins by email;
- explain that a phone call may be scheduled only when written troubleshooting cannot resolve the issue;
- do not publish a phone number.

- clear headings and anchor navigation;
- readable troubleshooting steps;

- release/download README;
