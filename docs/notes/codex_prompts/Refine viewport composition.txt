Viewport utilization

The interface currently leaves more unused space than necessary.

Improve viewport usage without making the UI feel crowded.

Implement fluid layout behavior using existing technologies where appropriate,
including concepts such as:

- flexible layout containers
- CSS Grid
- Flexbox
- min/max sizing
- clamp()
- viewport-relative spacing
- responsive gaps
- responsive typography
- responsive content widths

The application should expand gracefully on larger monitors while remaining
comfortable on smaller desktop windows.

Avoid rigid fixed spacing.

Avoid excessive maximum-width restrictions that make large displays feel empty.

Likewise, do not allow extremely wide unreadable content lines.

Favor balanced readable layouts.
