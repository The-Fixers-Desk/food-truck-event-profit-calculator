- Treat those initial values as the workspace baseline.

Labor:
- Zero or more employee labor entries

- Owner labor pay

Event costs and fees:
- Travel
- Parking
- Permit
- Generator or utility cost
- Vendor or booking fee
- Organizer commission
- Zero or more named miscellaneous costs
- Add and remove miscellaneous-cost rows while preserving order

Profit target:
- Profit target type

must not affect calculations.

Live recalculation

- Do not add a Calculate or Update Analysis button.
- Recalculate automatically after relevant assumptions change.
- Use a short debounce so ordinary typing does not create excessive requests.
- Send the complete current workspace assumptions to an appropriate Flask
  calculation endpoint.
- Validate and calculate through the existing Python form/domain/calculation
  logic.
- Do not reproduce business formulas in JavaScript.
- Return structured validation and result data suitable for updating the page.
- Ensure an older request cannot overwrite the results of a newer request.

Invalid live edits

- Show a concise status explaining that results will update after the invalid
  values are corrected.
- Do not create Event or Event Scenario records.

Updating state

Announce updated results and validation status accessibly without moving
keyboard focus.
