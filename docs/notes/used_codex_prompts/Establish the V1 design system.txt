Design objectives

The application should ultimately feel comparable in overall quality—not visual
imitation—to products such as:

- Notion
- ChatGPT
- Linear
- Stripe Dashboard
- Zillow

The goal is not to copy these products.

The goal is to reach the same level of clarity, consistency, restraint,
professionalism, and usability.

Design principles

Every design decision should follow these principles.

1. Looks like a professional desktop application, not a website.

2. Function before beauty.

Visual improvements must never reduce usability, readability, information
density, or workflow speed.

3. Decisions over decoration.

Every visual element should help users make faster or better business
decisions.

Avoid decoration that does not improve understanding, confidence, or
efficiency.

4. Strong visual hierarchy.

Every screen should have:

- one obvious primary action
- one obvious focal point
- predictable scanning order

5. Consistency over creativity.

Identical controls should always look and behave identically.

6. Low cognitive load.

Reduce unnecessary visual noise.

Reduce repeated wording.

Reduce unnecessary decisions.

7. Progressive disclosure.

Do not overwhelm users with secondary information.

Reveal complexity only when needed.

8. Fast scanning.

Important numbers, warnings, actions, and statuses should be identifiable
within seconds.

9. Desktop first.

Optimize for mouse, keyboard, and wide desktop layouts.

10. Reusable components.

Future screens should be assembled from shared design primitives rather than
screen-specific styling.
