Testing approach

- Domain or calculation tests for exact business rules

Scenario save and version actions

Add automated tests covering:

- An Original estimate Scenario is created automatically after valid Event
  submission.
- Save as new Scenario is the default save action.
- Saving as new creates a distinct Scenario.
- The original Scenario remains unchanged.
- The new Scenario becomes the active Scenario.
- Blank Scenario names are rejected.
- Duplicate Scenario names are rejected.
- Duplicate-name checks are case-insensitive.
- Overwriting requires explicit confirmation through the established workflow.
- Overwrite changes only the active Scenario.
- Overwrite does not create a duplicate Scenario.
- Reset changes restores the active saved Scenario baseline.
- Save is disabled or unavailable when the workspace has no unsaved changes,
  according to current behavior.
- A failed save preserves the current workspace values and calculated results.
- Existing saved custom-sales Scenarios remain loadable.
