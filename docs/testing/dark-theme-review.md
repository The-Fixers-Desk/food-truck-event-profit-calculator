# Dark-theme capability and visual review

Approved reference: `app/static/images/Dark Mode Food Truck App Audit.png`

## Capability inventory

- Onboarding and setup safeguards
- Dashboard and new analysis entry
- Business Defaults and six-stage Event Inputs workflows
- Event submission and Event Analysis live recalculation
- Scenario save, save as new, overwrite, reset, rename, and delete
- Saved Events search, sort, selection, and comparison
- Comparison baseline and differences-only controls
- Backup, restore, recovery, dialogs, dirty-navigation protection, and errors

## Manual review checklist

- [ ] Approved Dashboard hero copy, action, and two-column composition are unchanged
- [ ] Sidebar branding, navigation labels, icons, targets, focus, and selected state have confident scale
- [ ] Welcome, Dashboard, Business Defaults, and all six Event Inputs stages use dark surfaces
- [ ] Event Inputs step labels do not clip or create a desktop scrollbar
- [ ] Event Analysis keeps assumptions and results visible together; profit, target, and break-even remain primary
- [ ] Saved Events and two-to-four Scenario comparison remain readable with long names and many rows
- [ ] Data Safety, dialogs, empty, warning, success, validation, error, and recovery states are legible
- [ ] Keyboard-only focus is visible and reduced-motion behavior remains supported
- [ ] Small-laptop, medium, large, and ultra-wide layouts have no page-wide overflow

## Intentional differences from the reference

- The reference's right-side audit annotations are review notes, not application UI.
- The established line-icon family is retained; no unapproved logo asset was invented.
- No account/profile footer was added because V1 has no user-account capability.
- Recent work reflects actual saved data rather than the mockup's illustrative rows.
