# Guided form workflow manual review

Use an isolated application-data root.

- Complete Business Defaults using only the keyboard. Move Back and Continue,
  edit each review summary, then confirm only Save changes persists data.
- Complete Event Inputs on desktop and at narrow widths. Confirm the same six
  stages, logical Tab order, visible progress and reachable sticky actions.
- Submit invalid Defaults and Event Inputs. Confirm values and repeatable-row
  order remain, every invalid stage is marked and focus reaches the first error.
- Trigger and then correct contextual event warnings. Confirm they remain on
  their causal stage, never block Continue and disappear when corrected.
- Add, remove and rapidly enter several employee labor and additional-cost rows;
  confirm focus movement, announcements and row order.
- Review long business, Event and location names for wrapping without horizontal
  page scrolling or obscured actions.
- Verify the final Event review is concise, Edit returns to the right stage, and
  only Analyze event creates the Event and Original estimate Scenario.
- Reload after Save changes and confirm Business Defaults persisted; navigate
  stages before saving and confirm no partial values were stored.
