# Management views manual review

Use isolated application data with zero, one, and many Events and Scenarios.

- Complete first-use Welcome using only the keyboard; verify four compact steps
  and the single prominent Get started action.
- Review Dashboard with no work and recent work. Continue the latest Scenario
  and verify Analyze new event remains visually dominant.
- Search Saved Events by Event and Scenario names, clear the query, and verify
  the distinct no-results state. Sort by modified date, Event date, and name.
- Open, rename, and delete Events and Scenarios; verify duplicate-name and final-
  Scenario protections, confirmations, restart persistence, and long-name wrapping.
- Select two, three, and four same-Event and cross-Event Scenarios. Verify count
  announcements, selected styling, the four-item limit, and insufficient guidance.
- Change comparison baseline, toggle Show differences only, inspect ties and
  warning differences, and open every compared Scenario.
- Download a backup, reject an invalid restore, then complete a valid restore;
  confirm replacement wording and recovery-snapshot safeguards remain accurate.
- Repeat management, comparison, and Data Safety tasks at normal and narrow
  window sizes with keyboard navigation and visible focus.
