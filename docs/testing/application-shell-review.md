# Application shell manual review

Use an isolated application-data root.

- Complete fresh onboarding and confirm restricted navigation exposes only
  Welcome, Business defaults and Data safety.
- Launch normally after setup and visit Dashboard, New analysis, Saved events,
  Business defaults and Data safety. Verify current-page text, marker, border
  and focus state.
- Open Event Analysis and confirm the context bar handles long Event and
  Scenario names. Make unsaved changes, then cancel and confirm global
  navigation prompts; verify saved assumptions remain unchanged.
- Enter damaged-database recovery and confirm prohibited global destinations
  are absent while restore remains reachable.
- Review common desktop sizes and narrow widths down to 320 CSS pixels. Confirm
  the sidebar becomes the same compact navigation system, every destination
  remains reachable, source/Tab order stays logical and no page-wide overflow
  appears.
- Check screen-owned sticky actions for Event Inputs, Event Analysis, Defaults
  and comparison. Ensure they do not cover focus, headings, errors or content.
- Review Welcome, Dashboard, Defaults, Event Inputs, Event Analysis, Saved
  Events, comparison, Data Safety, recovery, not-found and application-error
  pages for appropriate content width, restrained boundaries, no duplicated
  page chrome and no excessive empty margins.
